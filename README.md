# hadisrehberi
Bu proje, İslam literatüründeki temel 6 hadis kaynağını tek bir yüksek performanslı SQLite veritabanında birleştirir. Hem komut satırı arayüzü (CLI) hem de gelişmiş bir Streamlit web arayüzü sunar.  JSON formatındaki hadis verileri [AhmedBaset/hadith-json](https://github.com/AhmedBaset/hadith-json) deposundan temin edilmiştir.
